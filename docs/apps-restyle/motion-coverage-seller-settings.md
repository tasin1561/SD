# Motion coverage — seller settings, team, notifications, profile (area E)

One line per page: every motion pattern and where it is. Shared pieces live in
`apps/seller/src/app/(authed)/settings/_components/settings-parts.tsx` (+ `settings.css`);
nothing on these pages animates on a refetch, no row has an entrance animation, and nothing
delays a navigation.

- **/settings** — Page header (breadcrumb). Grouped list rows (Account · Order and stock defaults · Money · Notifications · Integrations): hover lift, accent bar and chevron nudge on each row link. "This browser" card with the Motion switch (u08, ON/OFF in the track, per-user reduced-motion preference in localStorage). u27 empty state when nothing is open to the person.
- **/settings/security** — Page header with state facts. Skeleton pairs while identity hydrates. Rolling-label async button "Send me a new link" (idle → Sending… → Sent / Not sent) in a warn callout. Confirm dialog "Sign out everywhere?" (scale + fade open, focus trap, busy on the confirm button). Success callout after revoke; error callout with "Try again".
- **/settings/stores** — Page header with facts. KPI cards with the once-per-mount odometer (shopfronts, orders filed). Skeleton rows while loading. Data table with row hover; status chips (Default / Open / Closed). Confirm dialogs for Make default, Close and Reopen. Add / rename dialog with floating-label fields (name counter) and a rolling-label save (Saving… / Not saved). Toasts (u32) for results.
- **/settings/orders** — Section heading with a whose-figure fact. Skeleton while loading. Floating-label ₹ field. Rolling-label async "Save" (Saving… → Saved / Not saved) wired to the real PATCH. Toast on save; error callout.
- **/settings/stock** — Section heading with an Off / Warning-below fact. Skeleton while loading; error state with retry. Floating-label threshold field with live inline error. Rolling-label submit "Save" driven by `useAsyncState` over the real PATCH. Toast on save.
- **/settings/api-keys** — Page header with facts. Floating-label fields (key name with counter). Rolling-label "Create key". Confirm dialog on create (restates name and expiry) and on revoke (name · prefix). One-time reveal card (copy button, "Copied!" swap). Skeleton rows; data table with status chips; toasts.
- **/settings/webhooks** — Page header with facts. Endpoint cards with hover lift. Switch (u08) for enable/disable. Confirm dialogs for rotate secret and delete. One-time reveal card for a new secret. Form dialog (floating-label URL / name / description with counters / events) with a rolling-label submit (Creating… / Not created); server verdict shown verbatim. Skeleton while loading; u27 empty state with the primary action; toasts.
- **/settings/notifications** — Redirect to /notifications/settings; no UI.
- **/team** — Page header with facts. KPI cards with odometer. Member rows (hover tint, role chip or role select, You / Deactivated chips). Confirm dialogs for a role change (the select opens it; only Confirm sends), deactivate, and revoke invitation. Rolling-label "Resend" per invitation. Invite dialog with floating-label fields and a rolling-label submit. One-time invitation-link reveal card. Skeleton rows; data table with status chips; toasts.
- **/team/roles** — Page header with facts. Skeleton rows; data table with row hover. Confirm dialog on delete (replaces `window.confirm`). Role editor dialog: floating-label name and description, search field, permission groups as an accordion (grow + plus/minus morph; every group opens while searching), a switch per permission, rolling-label save, and a confirm dialog naming the permissions a save would remove.
- **/notifications** — Page header with facts. Rolling-label "Mark all read". Toolbar search. Liquid-bead tabs (u09) for All / Unread and for the kind groups, with counts. Inbox rows with hover tint and a kind-coloured edge; body expands in place. Rolling-label Mark read / Mark unread per row. Confirm dialogs for Dismiss (one) and Clear all. Skeleton rows; u27 empty state with "Clear filter" when filtering.
- **/notifications/settings** — Page header with whose-choice facts. Figure cards (odometer where the figure is a count). Topic groups as an accordion (all open by default, meta "n of m on"), a switch per topic (locked with the server's reason when immutable). Company categories table with switches and time fields; skeleton rows; error state with retry; toasts on save. Timezone card with an inside/outside quiet-hours chip (icon + words).
- **/profile** — Page header with facts. Figure cards for status, currency, payout bank and email. Skeleton cards while loading; error state with retry. Company info: floating-label fields (contact person counter), selects, rolling-label "Save changes". Bank details: floating-label fields, advisory warn callout, rolling-label "Send for approval" / "Save details", and a confirm dialog restating bank and masked account before the same PATCH fires; rejected / awaiting-approval callouts with status chips. Logo: file picker as a button whose label follows the real upload (Uploading… / Logo updated / Not uploaded, announced politely), and a confirm dialog on remove. Toasts throughout.
