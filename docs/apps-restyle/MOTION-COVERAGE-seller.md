# MOTION-COVERAGE — apps/seller

Every motion pattern used in the seller app, page by page (apps restyle,
Phase 3, 2026-09-23/24). Catalogue names are the premium-ui-motion skill's
(`u01`–`u35`, storytelling controls by name). Guardrails that hold on every
page: storytelling only on in-page async actions (≤ 1.2 s, never blocks the
next action), navigation is never delayed, no per-row table animation
(hover only), nothing re-animates on a refetch, and every pattern ends in
its correct state under reduced motion — the OS setting OR the per-user
"Reduce motion" switch on /settings (localStorage only), both handled by
the one path in `@skydrop/ui/brand/app.css`.

Not used in seller, and why: **van drive-off** — "Create order" navigates
to the new order immediately on success, and an animation may never delay
navigation (rolling label instead); **segmented code** — no seller page asks
for a one-time code.

## Shell, dashboard, sign-in

- **Shell (every signed-in page)**: u23 sidebar — sliding accent bar to the
  active row, collapsible groups whose rows fade/slide in ONLY when a person
  expands a group (never on mount), count badge on "Waiting on you"; u31 top
  bar; u20 drawer below `lg`; u14 theme switch (System / Light / Dark).
- **/dashboard**: KPI cards (u31) with glow by meaning; recent orders as the
  u07 table with StatusChips; needs-you as u21 list rows with severity
  stripes; onboarding progress bar and checks; shortcut cards lift and step
  their arrow on hover; skeleton rows; u27 empty / error states.
- **/login, /password-reset, /auth/***: shared SignInFrame — the corridor map
  fades in after first paint (lazy, never delays the form), the card rises
  (movement only, no fade: the heading is the LCP); u33 floating-label fields;
  u13 password strength meter and criteria chips on the three set-a-password
  forms; u28 sweep on the primary button.

- **/orders/import**: u15 DropZone for the CSV (lifts and tints on drag). "Download template" and "Upload and check" are rolling-label AsyncButtons. "Import N rows" is a controlled rolling-label AsyncButton. A **ParachuteProgress** line appears for the newest run once it is seen running. The loading skeleton is shaped like the page.
- **/tracking**: KpiCard glow and odometer on three cards (only unfiltered). There is a u33 search field. Liquid-bead Tabs for the six filters. Data table rows are hover-only. The expanded row is marked `selected`. The "History" / "Hide" control turns its chevron. The expanded parcel history is the **u17 Timeline**, the same one the public page draws. Reduced motion: every pattern above is handled by the global collapse in `brand/app.css`. The end states are correct with no motion: the filled connector, the checks, the final counts, the landed parachute and the rolled label.
