# Motion coverage — seller stock area (products, inventory, add stock, held stock)

One line per page: every motion pattern it uses and where. Patterns are the
`@skydrop/ui/app` primitives; reduced motion is handled globally by
`brand/app.css`, so each end state is correct with no motion. No per-row table
animation anywhere (row hover lift only, from the data table). Nothing delays
navigation: every link-styled button is a plain Next link.

- **/products** — KPI cards roll once (odometer, raw-count formatter) for active SKUs, units in stock and low on stock; liquid-bead tabs (u09) for the status filter in the table toolbar; data-table row hover lift; u16 pagination; shimmer skeleton while loading; u27 empty state with one next step (New product / Reset filters); u28 sweep on the New product and CSV import link-buttons.
- **/products/new** — floating-label fields (u33) throughout, option values as removable chips (focus glow); rolling-label AsyncButton on the sticky save bar ("Create product" / "Add the missing variants" → "Creating…"), wired to the real N-call submit; u28 sweep on Add value / Add an option / image picker buttons.
- **/products/[id]** — KPI cards roll once (variants, default weight); rolling-label AsyncButton for Archive / Restore product (trigger) and for Save changes in the edit form; ConfirmDialog (scale + fade, focus trap) before archive and restore; data-table row hover lift on variants; skeletons; u27 empty state ("Add variant"); toast (u32) on archive / restore.
- **/products/[id]/variants/[variantId]** — KPI cards; rolling-label AsyncButton for Archive / Restore variant, Save changes and the low-stock threshold Save; ConfirmDialog before archiving the variant and before deleting a picture; u15 drop zone (lifts and tints on drag-over) for pictures, upload rows with status chips; gallery tiles lift on hover; read-only u08 switch (On/Off in the track) stating strict unit tracking; skeletons; u27 empty state for no pictures; toast on threshold save.
- **/products/import** — rolling-label AsyncButton for Save mapping; ConfirmDialog before removing a saved mapping; dialog (scale + fade) for create / edit mapping; data-table hover; u27 empty state ("Save a mapping"); u28 sweep on Import history. (The CSV upload panel itself is `orders/_components/csv-import-panel.tsx`, outside this area.)
- **/products/import/jobs** — data-table row hover lift; u16 pagination; shimmer skeleton; u27 empty state ("Import a CSV"); status chips (icon + word).
- **/products/import/jobs/[id]** — **parachute progress** for the import run (indeterminate sway while PENDING / PROCESSING — the server reports no row progress, so no percentage is shown; lands on the server's status word when COMPLETED / COMPLETED_WITH_ERRORS, stop icon when FAILED / CANCELLED); KPI cards roll once (rows, products, variants, refused); rolling-label AsyncButton for Download the report; skeleton page while loading.
- **/inventory** — KPI cards roll once (India stock, in transit, low on stock); u35 tooltip card on the "In transit" label (glossary); the **low-stock chip pulses once** per row that is at or under its threshold (opacity + scale ring, never a loop); data-table row hover lift; u16 pagination; skeletons; u27 empty state with one next step (Inbound).
- **/inventory/units** — KPI cards roll once; u35 tooltip card on "Strict-mode SKUs only" (STRICT glossary); positive u27 empty states for each clean list; status chips; rolling-label AsyncButton on Trace (busy while the trace query fetches); floating-label serial field (Enter still submits); skeletons.
- **/inbound** — KPI cards roll once; liquid-bead tabs for the "Where" and "Route" filters; data-table row hover lift; u16 pagination; skeletons; u27 empty state ("Announce a consignment"). Announce dialog: **u34 stepper** as a progress header over the same single form (Route → Contents → Arrival and reference; the connector fills as the contents are listed), u10 choice cards for the route, u12 number stepper for quantity, u33 fields and date fields, checkbox for dated goods, rolling-label AsyncButton "Announce N products" → "Announcing…".
- **/inbound/[id]** — **u17 timeline** for "What has happened" (filled connector, the latest event pulsing as the current step while the consignment is still moving, time chips; earlier steps fold behind one button past four); KPI cards roll once; u35 tooltip card on "Still to come"; per-stop panels with count tables (hover only); cancel dialog restating the consignment with a rolling-label destructive AsyncButton; correct-contents dialog with u12 steppers, date fields and a rolling-label Save corrections; toasts on cancel and correction; skeletons.
- **/holds** — KPI cards (awaiting-you count rolls once); liquid-bead tabs for the status filter; data-table row hover; positive u27 empty state when nothing waits; decide dialog restating the order and units, u10 choice cards for Release / Keep trying, rolling-label AsyncButton (destructive tone for Release); toast on the decision.
